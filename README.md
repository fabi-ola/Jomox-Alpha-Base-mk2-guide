# Jomox Alpha Base MK2 — Interactive Manual

This is open-source, interactive learning guide for the Jomox Alpha Base MK2 drum machine. I used codex to help visualize the original Jomox Alpha Base mk2 manual and how to navigate the machine. 

The project is very simple (an html file) - I wanted something quick and easy to digest information from the original manual easier to explore. I added a simple guide on how to start building a pattern. The project is not intended to cover the entire functionality of the machine. Feel free to use, modify, and build upon it as you wish.

Visuals only; no audio included in the demonstration.
